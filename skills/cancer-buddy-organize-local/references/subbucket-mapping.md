# Sub-Bucket Mapping — cancer-buddy-organize-local (`scheme_version: 3`)

> 14 clinical domains (+2 infra) 的子桶映射。Layer 2 (Claude vision 分类) 必须把每个文件落到具体子桶，不能停在桶级。

> 分类是**阅读理解判断，非关键词匹配**：下表的"识别线索"是辅助参考，不是 regex 白名单。

## 子桶判定规则（Layer 2 决策树）

读 `ocr/<basename>.md` 文本后**通过阅读理解判断**（非关键词匹配）按下列顺序判：

### 步骤 1：粗桶 (01-14)

跳过 `90_`（mirror）、`99_`（quarantine）—— 这两类不是分类目标，由去重 / 相关性门控写入。从 `01_…14_` 14 个临床域里选 1。

### 步骤 2：细桶（仅当粗桶有子桶时）

#### 07_检验

按 OCR 文本中**主要检测项目**的多数派判定：

| 主要项目 | 子桶 |
|---|---|
| WBC + RBC + HGB + PLT 占主体 (CBC) | 血常规/ |
| ALT + AST + 胆红素 + 肌酐 + 电解质 + 白蛋白 + LDH + GGT + 血脂 + 血糖 占主体 | 生化肝肾功/ |
| CEA / CA199 / CA125 / AFP / SCC / HE4 / VEGF / NSE / Cyfra21-1 / proGRP / PSA / 神经特异烯醇酶 | 肿瘤标志物/ |
| PT / INR / APTT / D-dimer / 纤维蛋白原 | 凝血/ |
| 尿常规 / 便常规 | 尿便/ |
| 免疫球蛋白 / C3/C4 / 自身抗体 / 病毒五项 / 淋巴亚群 (CD3/CD4/CD8/B/NK) / 甲功 / 性激素 / 心脏标志物 / ESR / CRP / PCT / Vit D / B12 / 叶酸 / HbA1c 等 | 其他/ |

**易混淆的 lab 路由 — 必查**（针对常见误分类）：

| 项目 | 易误判到 | 正确子桶 | 理由 |
|---|---|---|---|
| **ESR (血沉/红细胞沉降率)** | 血常规/ ❌ | **其他/** ✅ | ESR 不是血常规 (CBC) 的一部分；它是非特异性炎症指标，与 CRP/PCT 同类 |
| **CRP (C-反应蛋白)** | 生化肝肾功/ ❌ | **其他/** ✅ | 急性期反应物，不是肝肾功 |
| **Procalcitonin (PCT)** | 其他/ | **其他/** ✅ | 感染标志物，按"非特异炎症"归 其他 |
| **Vit D / B12 / 叶酸 / 铁蛋白** | 生化肝肾功/ ❌ | **其他/** ✅ | 营养/微量元素类，归 其他 |
| **HbA1c** | 生化肝肾功/ ⚠️ | **其他/** ✅（也可入 生化） | 血红蛋白糖化 |
| **β-HCG** | 其他/ ⚠️ | **其他/** ✅（妊娠相关）或 **肿瘤标志物/**（GTN/绒癌） | 看文档语境 |
| **NT-proBNP / 肌钙蛋白 / BNP / CK-MB** | 生化肝肾功/ ❌ | **其他/** ✅（心脏标志物归 其他） | 不要进 生化 |
| **PSA (前列腺特异)** | 其他/ ❌ | **肿瘤标志物/** ✅ | 是肿瘤标志物 |

**多项目混合**：选项目数最多的子桶；并列时按表格顺序优先（血常规 > 生化 > 肿标 > ...）。

### 步骤 4：confidence 处理

Layer 2 输出每个文件的 `classification_confidence ∈ [0, 1]`：
- ≥ 0.7 → 进目标子桶
- 0.5–0.7 → 进目标子桶 + flag `low_confidence_classification`（写进 readiness.warnings）
- < 0.5 → 进 `99_无关文件/uncertain/` 等待人工 review

## 子桶 vs 桶级 — 何时 fallback 到桶级

如果 OCR 文本不足以判子桶（典型：PaddleOCR 失败 / 图片是手机拍的检验单一角，关键标题缺失）：

- `05_影像/` 但无法判子类 → `05_影像/其他/`
- `06_分子与组学/` 但无法判子类 → `06_分子与组学/其他/`
- `07_检验/` 但无法判子类 → `07_检验/其他/`
- `08_治疗/` 但无法判子类 → `08_治疗/支持治疗/`（最不会错）
- 无法判桶 → `99_无关文件/uncertain/`

**禁止**写到桶根目录（如 `05_影像/foo.jpg`）。每个文件必须落到子桶。

## 癌种特异子桶相关性表（用于空子桶清理决策）

骨架把所有子桶建出来，但很多子桶只对特定癌种相关。Layer 2 完成后，**空且无关**的子桶应删掉。下表标注每个易"无关"子桶的相关癌种，**不在列内的癌种 + 子桶为空 → 删**。

| 子桶 | 主要相关癌种 | 反例（应删的癌种） |
|---|---|---|
| `06_分子与组学/其他/`（HPV 分型） | 宫颈癌、口咽癌、肛管癌、外阴/阴道癌、部分头颈鳞癌 | 胰腺癌、肝癌、肺腺癌、乳腺癌、血液病 → 删 |
| `05_影像/超声/` | 乳腺癌、甲状腺癌、肝胆胰癌（部分）、妇科癌（经阴道）、心动图 | 大多数实体瘤如非乳/肝/妇 → 没装就删 |
| `07_检验/其他/`（淋巴亚群） | 血液病（淋巴瘤、白血病、MM、MDS）、骨髓移植后、HIV 合并癌 | 实体瘤一般无 → 没用到就删 |
| `07_检验/其他/`（性激素） | 妇科癌（卵巢/子宫内膜/乳腺）、前列腺癌、生殖细胞肿瘤、内分泌肿瘤 | 胰腺、肺、消化道 → 没用到就删 |
| `07_检验/其他/`（心脏标志物） | 蒽环类化疗后心毒性监测、HER2 靶向治疗（曲妥珠/T-DXd）心毒性、放射性心脏病 | 没用蒽环 / 没 HER2 靶向治疗 → 没装就删 |
| `08_治疗/放疗/` | 多数实体瘤都可能有；血液病（淋巴瘤 ISRT）也有 | 罕见情况无放疗 → 删 |
| `08_治疗/免疫治疗/` | 已 PD-L1+/MSI-H/TMB-H 接受 ICI 的患者 | MSS+CPS<1+TMB-L → 通常没 ICI → 没装就删 |
| `08_治疗/靶向/` | 有可靶向驱动突变的患者 | 无可靶向突变 → 没装就删 |
| `08_治疗/内分泌/` | 激素受体阳性乳腺癌 / 前列腺癌 / 子宫内膜癌 | 无内分泌适应症 → 没装就删 |

**对一个 PDAC（胰腺癌）患者的应用示例**：
- ✅ 删: `06_分子与组学/其他/`（HPV，PDAC 不相关）、`08_治疗/内分泌/`（无适应症）
- ✅ 保留即使空: `14_患者自管补充/*`（用户后续可补）、`90_原始文件镜像/_duplicates/`、`99_无关文件/uncertain/`、`04_诊断与分期/诊断证明/`
- ✅ 保留有内容: 已用到的子桶
